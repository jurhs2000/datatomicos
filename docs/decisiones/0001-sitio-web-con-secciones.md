# 0001. El producto es un sitio web con secciones

- **Fecha:** 2026-11-24
- **Estado:** aceptada

## Contexto

El proyecto reúne dos piezas: un explorador de las publicaciones del INE por tiempo y territorio, y un análisis del IPC con proyección. Se podían presentar como un solo producto con una vista, como dos productos separados o como un sitio con secciones.

## Decisión

Un sitio web con secciones. La versión inicial tiene dos: el explorador y el IPC con proyección.

## Consecuencias

- Las secciones se desarrollan en paralelo y comparten navegación y lenguaje visual.
- Agregar una sección no debe obligar a modificar las existentes.
