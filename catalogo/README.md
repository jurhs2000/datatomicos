# Catálogo de publicaciones

Metadatos de cada publicación del INE que entra al sitio: periodo, nivel territorial, base o versión metodológica, fuente y fecha de descarga. Es la pieza que lee la interfaz (ver [docs/decisiones/0003](../docs/decisiones/0003-catalogo-de-publicaciones.md)).
